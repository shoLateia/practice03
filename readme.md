# Practice03 - UI Parts Implementation

JavaScript を用いた主要な UI コンポーネントの実装練習リポジトリです。

## 🚀 デモ

[https://sholateia.github.io/practice03/](https://sholateia.github.io/practice03/)

## 🛠 実装機能

実用的な 4 つの UI 機能を Vanilla JS で実装しています。

-   **Tab Menu**: 効率的なコンテンツ切り替え
-   **Accordion**: 省スペースな情報表示
-   **Smooth Scroll**: 快適なページ内遷移
-   **Intersection Observer**: スクロール検知による動的演出

## 📂 技術スタック

-   HTML5 / CSS3
-   JavaScript (ES6+)
